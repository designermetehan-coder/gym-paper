# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow the App Store releases.

## [1.1.1] - 2026-11-06

### Added
- Open source release: MIT license, documentation, contribution guides.
- Signing via `Config/Signing.xcconfig`; local Team ID is no longer committed.
- `apps/web/.env.example` for optional cloud backup.

### Changed
- Repository reorganised into `apps/ios`, `apps/web`, `apps/site` and `backend/supabase`.
- Licensed MoveKit animations removed from the repository; apps fall back to free-exercise-db photos.

## [1.1.0] - 2026-11

### Added
- English localization for the app, App Store page and website.
- Intermittent fasting stages, MoveKit 3D exercise animations (App Store build only).
- Redesigned Summary: weekly recap and 365-day activity map.
- iPhone Duo (foldable) layouts.

## [1.0.0] - 2026-10

### Added
- First App Store release: workout player, nutrition log, fasting, widgets, Apple Watch app.
